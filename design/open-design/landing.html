How it fits together

Four ways in. One notebook underneath.

Every client talks to a single PocketBase server. It holds the truth; the clients bring their own merge.

PhoneAndroid, offline copy
WebServed by the server
CLINotes and tasks from the shell
ExtensionChrome clipper
One PocketBase server

On a machine you own. Reached only over your private network.

NotesTasksPhotos and PDFsChat agentAuto-tagger

Every write carries the version it was based on. A stale one is refused, and the client merges field by field before it tries again.

Tailscale in front. No accounts, no public port.

Themes

Black as a screen can be. Or paper.

Sixteen themes, each its own palette: from the true black that rests on OLED to warm sepia, with Catppuccin, Nord, Rosé Pine, Tokyo Night, Gruvbox and Solarized among them. This page wears the first.

And eight accent colours to lay over any of them.

Yours in a couple of commands.

Start the server on any machine with Docker, then point the app, the browser and the terminal at it.

$ git clone https://github.com/your-name/tefnotes.git
$ cd tefnotes/server
$ docker compose up -d --build
